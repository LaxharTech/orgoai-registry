# Kokoro voice pack: pronunciation dictionaries

`us_gold.json` and `us_silver.json` are the American English pronunciation dictionaries from
misaki 0.9.4 (hexgrad/misaki, Apache-2.0, see `MISAKI-LICENSE`), unchanged. Swasth's on-device
Kokoro voice (pack `tts-heart`, KF.17b) reads them with olai's own G2P. Nothing here comes from
eSpeak NG.
